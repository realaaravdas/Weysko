Frequently Asked Questions

How do I launch my exported website?

Export as a Folder or ZIP and upload to GitHub Pages, Netlify Drop, Cloudflare Pages, Nginx, or any Apache/S3 static host.

How does Google Sites integration work?

Choose Export → Google Sites, click Copy Embed HTML, then inside Google Sites open Insert → Embed → Embed code and paste.

Does Weysko use AI or external cloud servers?

Never. Weysko is 100% deterministic Rust running locally on your machine with full manual design control.

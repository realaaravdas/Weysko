Using Weysko Studio v1.3.1

1. Adobe-Style Start / Home Screen

When you open Weysko with no file argument, the creative Start screen lets you choose how to begin:

  • Website Style Strip: Pick any of the 6 curated visual themes (Obsidian Slate, Pure Editorial, Midnight Mono, Nordic Steel, Warm Alabaster, Carbon Ink) before opening a template.
  • Templates & Examples: Start directly from Meridian Cloud, Minimalist Portfolio, SaaS Landing, Design Agency, or Personal Bio.
  • New from Scratch: Specify site name, base URL, and initial structure (blank strip, single-page hero, or 3-page skeleton).
  • Past Projects & Import: Reopen recently saved .weysko / .weysko.json projects or import any file from disk.

2. Designing on the Visual Canvas

Inside the Studio workspace, all layout controls remain direct and deterministic:

  • Left Rail Drawers: Switch between Add (16 primitives), Strips (13 section layouts), Sites, Layers, Theme, and Media.
  • Canvas Manipulation: Drag elements with optional 8px grid snapping and smart alignment guides, resize from all 8 handles, or double-click any heading, paragraph, button, or badge for inline editing.
  • Right Inspector: Fine-tune Content, Layout (including Desktop/Tablet/Mobile overrides), Style (fills, typography, shadows, padding), and Hover/Entrance effects.
  • Status Bar: Inspect live coordinates, strip/element counts, theme badge, preview URL, and unsaved status at a glance.

3. Saving & Exporting (.weysko + 4 Targets)

Use Ctrl+S to save editable work or open Export / Publish for five deployment options:

  • .weysko Project File: Portable JSON envelope bundling pages, sections, design tokens, responsive rules, and base64 assets.
  • Static Folder: Multi-page HTML5, styles.css, site.js, decoded assets/, 404.html, and optional sitemap.xml / .nojekyll.
  • ZIP Archive: Compressed package ready for Netlify Drop or Cloudflare Pages.
  • Single-File & Google Sites: Self-contained HTML with inline routing; paste directly into Google Sites via Insert → Embed → Embed code.

4. Embedded Live Preview Server

Click Live Preview in the top bar (or run weysko --serve) to launch an embedded pure-Rust HTTP server (tiny_http) on localhost:

  • Every canvas edit automatically refreshes the in-memory preview server so refreshing your browser shows the latest HTML/CSS immediately.
  • Press the Home button in the top-left whenever you want to return to the Start screen without losing your active editing session.

Step-by-Step Tutorial: Building “Meridian Cloud”

Follow these six steps to recreate, customize, and export the 3-page Meridian Cloud infrastructure example shipped with Weysko v1.3.1.

STEP 01

Choose Obsidian Slate on the Start Screen

Launch Weysko Studio. In the Start screen style bar, select Obsidian Slate (#090D16 canvas, Inter + JetBrains Mono). Click Meridian Cloud (Example Site) or start from a 3-page New from Scratch skeleton to open the editor.

STEP 02

Author the Split Hero & Topology Media

Select the hero strip on /index.html. Double-click the H1 element to edit “Deterministic edge compute for distributed teams.” Use the Media drawer to import meridian-topology.png and click Use on Selected with the hero image frame selected.

STEP 03

Configure Feature Cards & Page Links

Insert a Features 3-Column strip below the hero, double-click each card’s title and body in the Inspector Content tab, and wire the Navbar CTA button (“Deploy Now”) to page slug contact so both multi-page HTML and Google Sites embeds navigate seamlessly.

STEP 04

Add Pricing Tiers, FAQ & Contact Form

Use the top-bar page switcher to open /pricing.html and /contact.html. Insert the Pricing Tiers and FAQ Accordion strips on Pricing, then a Contact Form strip on Contact using native <details> expand/collapse and toast submission feedback.

STEP 05

Preview Tablet & Mobile Breakpoints

Click Desktop / Tablet / Mobile in the top toolbar to verify 1280px, 768px, and 390px reflow. Weysko’s Auto Stack mode orders mobile cards top-to-bottom automatically without overlapping elements.

STEP 06

Export .weysko + Live Static Folder

Press Ctrl+S to save meridian-cloud.weysko (so it appears in your Start screen’s Past Projects), then open Export / Publish → Static Folder to compile the production site. Inspect the compiled Meridian Cloud output ›

CLI Reference & Build From Source

Headless CLI Commands

Automate template creation, multi-target exports, and preview servers in CI or terminal scripts:

WEYSKO CLI 
# Create portable .weysko project file
weysko --init-template meridian --out meridian-cloud.weysko

# Export static folder, ZIP, Google Sites embed, or .weysko bundle
weysko --export meridian-cloud.weysko --out ./dist --format folder
weysko --export meridian-cloud.weysko --out ./site.zip --format zip
weysko --export meridian-cloud.weysko --out ./embed.html --format google-sites
weysko --export meridian-cloud.weysko --out ./backup.weysko --format weysko

# Launch embedded HTTP preview
weysko --serve meridian-cloud.weysko --port 8080

Compile From Source (Windows, macOS, Linux)

Install the Rust toolchain via rustup.rs, then build the workspace:

BUILD STEPS 
# 1. Debian / Ubuntu system libraries (Linux only):
sudo apt-get update && sudo apt-get install -y \
  libgtk-3-dev libxcb-render0-dev libxcb-shape0-dev \
  libxcb-xfixes0-dev libxkbcommon-dev libgl1-mesa-dev pkg-config

# 2. Clone & build release binary (all platforms):
git clone https://github.com/realaaravdas/Weysko.git
cd Weysko
cargo build --release --bin weysko

# 3. Run unit & integration checks:
cargo test --workspace

Architecture

Designed like a studio. Compiled like a build tool.

Weysko never calls external models or cloud APIs. Your layout, typography tokens, and embedded assets compile locally in Rust into predictable HTML5, CSS3 variables, and vanilla JS.
Save or exchange complete sites in portable .weysko format, export multi-page folders for Nginx or GitHub Pages, create a ZIP for Netlify Drop, or copy a single-file bundle into Google Sites.
Built on egui/eframe and tiny_http with zero Electron or Node.js runtime overhead. Available as a Windows Setup Installer, macOS Apple Silicon .dmg, and Linux .AppImage & .deb.

Build From Source

Requires Rust stable (1.75+). On Linux, install GTK3, XCB, xkbcommon & OpenGL headers first:

TERMINAL (RUST / CARGO) 
git clone https://github.com/realaaravdas/Weysko.git
cd Weysko
cargo build --release --bin weysko

# Windows installer binary (optional):
powershell -ExecutionPolicy Bypass -File .\scripts\build-installer.ps1

Linux Debian/Ubuntu build deps: sudo apt install libgtk-3-dev libxcb-render0-dev libxcb-shape0-dev libxcb-xfixes0-dev libxkbcommon-dev libgl1-mesa-dev pkg-config. Full build instructions ›

Google Sites Embed Workflow

Launch multi-page Weysko sites inside Google Sites without an external server:

WORKFLOW 
1. Open Weysko Studio → click "Export / Publish"
2. Select the "Google Sites" tab
3. Click "Copy Embed HTML to Clipboard"
4. In Google Sites: Insert → Embed → Embed code
5. Paste bundle, click Next → Insert, resize full-width

Headless CLI & .weysko Reference

Initialize starter .weysko projects, export across all 5 targets, and serve previews:

TERMINAL 
weysko --init-template meridian --out site.weysko
weysko --export site.weysko --out ./dist --format folder
weysko --export site.weysko --out ./site.zip --format zip
weysko --export site.weysko --out ./copy.weysko --format weysko
weysko --serve site.weysko --port 8080
